# Fontes visuais da CC05

Os PNGs originais usados na cena ficam em `Assets/Art/CC05`. Eles vieram da pasta `Cenário e ambiente/andar4` do Drive compartilhado para o jogo:

`https://drive.google.com/drive/folders/1Th1ifT5kDRAj3V3TbBKzppTCY1JdIVel`

| Arquivo local | Origem no Drive | Uso na cena |
| --- | --- | --- |
| `fundo_andar4.png` | `fundo_andar4.png` | Fundo 640×360 do salão noturno. |
| `painel.png` | `objetos/painel.png` | Quadro elétrico aberto. |
| `painel_faiscas_sheet.png` | `objetos/painel_faiscas_sheet.png` | Três quadros de faíscas controladas no painel. |
| `obra_apagada.png` | `objetos/obra_apagada.png` | Obra principal durante toda a CC05. |
| `ceu_noite.png` | `objetos/ceu_noite.png` | Céu visível no início, limitado às vidraças da basculante. |
| `ceu_amanhecer.png` | `objetos/ceu_amanhecer.png` | Gradiente de amanhecer aplicado só às vidraças. |

As imagens de prova da pasta `andar4` serviram para posicionar o painel, a obra e o céu; elas não são usadas como fundo final. A cena usa os sprites existentes em `Assets/Art/Characters` e `Assets/Art/CC04A` para manter o desenho e as proporções dos personagens consistentes com as cutscenes anteriores.
